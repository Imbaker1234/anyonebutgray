# Anyone But Gray

Separate static React/Vite website for anyonebutgray.com.

## Local Commands

```powershell
npm install
npm run dev
npm test
npm run build
```

## Launch Gate

Do not publish until the sponsor and disclaimer text in
`src/content/siteConfig.ts` is reviewed and finalized. The site is structured to
avoid anonymous or hidden-authorship promises; public launch should use the
required political-ad disclaimer language.

## Evidence Rules

- Publish public records, reputable news, court docket context, and legal
  compliance context only.
- Label lawsuits as allegations unless and until there is a final adjudication.
- Keep social posts, personal anecdotes, and unsupported office-availability
  claims out of the published evidence.
- Place unverified concerns in records requests, not as factual claims.
